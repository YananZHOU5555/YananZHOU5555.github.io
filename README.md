# Yanan Zhou — academic website

A lightweight English academic website for `yananzhou.me`.

## Local preview

Open `index.html` directly, or serve this folder with any static file server.

## Content to add before final publication

- Replace publication media placeholders with approved GIFs, videos, or figures.
- Add a revised public CV that reflects the current robotics research direction.
- Add code and project-page links after they are ready for public release.

## Deployment

The folder can be deployed directly to Cloudflare Pages. No build command is required; the output directory is the repository root.

## Visual effect attribution

The subtle hero thread field is adapted from React Bits' WebThreads component and bundled with OGL. Third-party notices are stored in `assets/licenses/`.

## Paper demos

Every publication has a fixed 16:9 GIF demo slot. Asset names and the replacement pattern are documented in `assets/demos/README.md`.
